# VanillaLOD

Level of Detail을 서버 모드와 리소스팩을 이용해 지원하는 프로젝트

**26.3 버전을 지원하고 있다**

---

## 특징

- 클라이언트 모드 없이 바닐라 리소스팩을 활용
- 텍스트 디스플레이가 지형 데이터를 담고 있음
- 겹치는 청크를 공유하는 최적화
- 거리에 따라 지형 크기를 다르게 그림
- 실제 블록 텍스처와 바이옴 색을 반영
- 바닐라 안개와 이어지는 지평선 안개
